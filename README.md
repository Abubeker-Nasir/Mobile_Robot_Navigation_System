# Mobile Robot Navigation System using Deep Reinforcement Learning

A reinforcement learning-based autonomous mobile robot navigation system developed using Python, PyTorch, and Gymnasium. The project simulates a differential drive mobile robot navigating through a maze environment using LiDAR-based sensing and Deep Q-Network (DQN) learning.

## Project Overview

This project focuses on autonomous mobile robot navigation in a maze environment using Deep Reinforcement Learning (DRL). The robot learns obstacle avoidance and goal-reaching behavior through interaction with a custom simulation environment.
